<objective>
Replace unsafe PostgreSQL URL string interpolation with SQLAlchemy URL.create()

Purpose: Eliminate SQL injection vulnerability in database connection string construction. The current code uses f-string interpolation (`f"postgresql://{user}:{password}@..."`) which doesn't escape special characters in credentials. If a password contains characters like `@`, `:`, `/`, or `%`, the URL parsing will fail or be misinterpreted, potentially exposing credentials or allowing injection attacks.

Output: Safe database URL construction using SQLAlchemy's URL.create() method in vectordb.py and alembic env.py.
</objective>
