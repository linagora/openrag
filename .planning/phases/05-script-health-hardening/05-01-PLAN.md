<objective>
Enhance the health check endpoint to probe LLM and VLM services and report their availability with response time metrics.

Purpose: The current health endpoint (line 189-192 of api.py) returns a static string and provides no observability into external service health. This makes it impossible for orchestrators (Kubernetes, monitoring) to detect when LLM/VLM services are down. DEBT-01 requires reporting LLM and VLM service availability with response time metrics.

Output: Enhanced `/health_check` endpoint returning structured JSON with per-service status, response times, and appropriate HTTP status codes (200 healthy, 503 degraded/unhealthy).
</objective>

  <action>
Replace the existing health_check endpoint (lines 189-192) with an enhanced version that probes external services.

Add a helper function `check_service_health(base_url: str, service_name: str)` at module level (above the endpoint) that:
- Creates an `httpx.AsyncClient` with `timeout=httpx.Timeout(3.0)` (per Phase 01 decision: use simple httpx.Timeout(float) form)
- Sends GET to `{base_url}/health` (VLLM standard health endpoint)
- On success (200): returns `{"status": "healthy", "response_time_ms": round(elapsed_ms, 2)}`
- On non-200: returns `{"status": "unhealthy", "error": f"HTTP {response.status_code}", "response_time_ms": round(elapsed_ms, 2)}`
- On `httpx.TimeoutException`: returns `{"status": "timeout", "error": "Service did not respond within 3s"}`
- On `httpx.ConnectError`: returns `{"status": "unreachable", "error": "Connection refused"}`
- On generic `Exception`: returns `{"status": "error", "error": str(e)}`
- Use `response.elapsed.total_seconds() * 1000` for response time (httpx built-in, per research don't-hand-roll guidance)

Replace the `health_check` endpoint to:
- Get config via `request.app.state.app_state.config`
- Run LLM and VLM checks concurrently using `asyncio.gather(..., return_exceptions=True)`
- Handle gather results: if a result is an Exception (shouldn't happen with try/except in helper, but defensive), treat as error status
- Build response with: `{"status": overall_status, "checks": {"api": {"status": "healthy"}, "llm": llm_result, "vlm": vlm_result}, "timestamp": time.time()}`
- LLM is critical: if LLM status != "healthy", overall = "unhealthy", HTTP 503
- VLM is non-critical: if only VLM unhealthy but LLM healthy, overall = "degraded", HTTP 200 (per research recommendation: VLM only used for image captioning)
- If both healthy, overall = "healthy", HTTP 200
- Return `JSONResponse(status_code=..., content=...)` (JSONResponse already imported in api.py)

Add required imports at the top of api.py (near existing imports):
- `import asyncio` (for asyncio.gather)
- `import time` (for timestamp)
- `import httpx` (for async health probes)

Do NOT add caching for now (research recommends starting without it).
Do NOT add vectordb health check (not in DEBT-01 requirements).
