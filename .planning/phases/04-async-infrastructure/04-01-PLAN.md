    In `base.py`, convert `save_content` from sync to async following the pattern already established by VideoAudioLoader in media_loader.py:

    1. Add `import asyncio` at the top of base.py (if not already present).

    2. Create a private sync helper `_write_file(self, path: str, content: str)` that contains the actual blocking file write:
       ```python
       def _write_file(self, path: str, content: str):
           with open(path, "w", encoding="utf-8") as f:
               f.write(content)
       ```

    3. Convert `save_content` to async:
       ```python
       async def save_content(self, text_content: str, path: str):
           path = re.sub(r"\..*", ".md", path)
           await asyncio.to_thread(self._write_file, path, text_content)
           logger.debug(f"Document saved to {path}")
       ```

    Then update the 5 simple callers (loaders that ONLY need `await` added to save_content, no other blocking I/O fixes):

    - `txt_loader.py` line 43: change `self.save_content(content, str(path))` to `await self.save_content(content, str(path))`
    - `txt_loader.py` line 79: change `self.save_content(text_content=content, path=str(path))` to `await self.save_content(text_content=content, path=str(path))`
    - `media_loader.py` line 231: change `self.save_content(content, str(file_path))` to `await self.save_content(content, str(file_path))`

    - `openai.py` (PDF loader) line 61: change `self.save_content(markdown, file_path)` to `await self.save_content(markdown, file_path)`

    Do NOT modify docx.py, image.py, pptx_loader.py, or pymupdf.py here -- those are handled in Plan 02 which also wraps their other blocking I/O.
