<objective>
Convert all 6 loaders with blocking file I/O to use asyncio.to_thread, eliminating event loop blocking during file operations (PERF-02).

Purpose: These loaders perform blocking file reads (open/read), library calls (zipfile, cairosvg, PIL, pymupdf4llm, pptx.Presentation, spire.doc), and file cleanup (os.remove) directly in async methods, blocking the event loop. Wrapping these with asyncio.to_thread follows the existing pattern from VideoAudioLoader (media_loader.py).

Output: All 6 loaders use non-blocking file I/O via asyncio.to_thread.
</objective>

       ```python
       def _convert_doc_to_docx(self, file_path):
           """Convert .doc to .docx using Spire.Doc (blocking operations in thread pool)."""
           document = Document()
           document.LoadFromFile(str(file_path))
           with tempfile.NamedTemporaryFile(delete=False, suffix=".docx") as temp_file:
               temp_path = temp_file.name
               document.SaveToFile(temp_path, FileFormat.Docx2016)
           return document, temp_path
       ```

    2. In aload_document, use asyncio.to_thread for the conversion and cleanup:
       ```python
       async def aload_document(self, file_path, metadata, save_markdown=False):
           document, temp_path = await asyncio.to_thread(self._convert_doc_to_docx, file_path)
           try:
               result_string = await self.MDLoader.aload_document(temp_path, metadata, save_markdown)
           finally:
               await asyncio.to_thread(os.remove, temp_path)
               document.Close()
           return result_string
       ```
       Note: `document.Close()` is a quick in-memory operation, doesn't need thread wrapping. But wrap os.remove as it's file I/O.
